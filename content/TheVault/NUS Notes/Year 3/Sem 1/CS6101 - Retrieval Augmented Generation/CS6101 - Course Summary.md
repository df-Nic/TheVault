# Work Explanation
---
## Lecturing

- Leading a lecture / discussion based on the papers read
	- Decide on 2-3 papers and give a 5-10 minutes lecture for each paper
	- Design slide deck
	- Focus on the points rather than the results
## Support

- Support the lecturing team
	- Scribe
	- Create a quiz with 5 - 10 questions to be done in the next week
	- Edit the recording to be posted on YouTube Channel (Thumbnails,  Subtitles, etc) 
	- Update the GitHub repository (Both the website & the document bank)
## Group Project

- A group project can be anything related to retrieval augmented generation (RAG)
	- A total of **5 sprints**
	- On **week 4 & every alternating Thursdays** there is a consultation from 13:00 - 15:00
	- On **week 13**, there will be a public project showcase
